## Minor
1. **Offline cache misses the pixel art.** `web/sw.js` FILES lists every stamp and placeholder, but not `stamps/px/*.png` (48 files: the music player's track art via `muArt`, and `pxSrc`). In the installed web app those load from the network, so offline they're blank. Repro: load the web build once, go offline, open the music player. Add `stamps/px/…` to FILES (and bump the cache if that ships).
2. **Web Mochi shows no thinking state.** In `?web`, `__mb.ask('make a flowchart for onboarding')` adds the message and answers after her 900 ms pause, but during it `#mcStatus` is empty, no `.typing` row appears and `#mochi` never gets `thinking`. The Mac path (`typing(true, doingLabel(q))`) is where her doing-label lives, so this is web-only; not verified on the Mac here.
3. **Settings → About shows no version in the web build** (the number comes from `MB.version()`, native only). Expected for the web; confirm 1.8.0 shows in the Mac app's About and the update row.
4. **Observation, not a bug:** a selected card's connector dots are in the DOM but invisible until the pointer is over the card (opacity 0 → 1 on hover); with the Connector dots setting off, a note shows none on hover and a flowchart piece still shows four. Matches the setting's text.
5. **Harness note for next time:** `maskWithShape(shape, card)` takes one card, not an array. Passing an array half-builds a group (mask layer grouped, member not, nothing clipped). Internal only; no UI path does this.
